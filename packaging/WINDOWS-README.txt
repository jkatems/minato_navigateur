Minato pour Windows 10/11 x64

Archive ZIP : extraire TOUT le dossier, puis ouvrir bin\minato.exe.
Installateur : executer le setup et utiliser le raccourci Minato du menu Demarrer.
Les DLL, plugins, ressources et QtWebEngineProcess.exe doivent rester ensemble.
Aucune installation de Qt ni de Visual Studio n'est necessaire sur le poste destinataire.

Les profils sont conserves dans le dossier de donnees du compte Windows,
independamment du dossier de l'application. Une mise a jour ou une desinstallation
ne supprime pas volontairement les profils.

Ce build n'est pas signe numeriquement. Une validation sur un Windows propre reste
necessaire avant diffusion publique ; voir les documents du projet pour les licences.
